# FTL Gym Parallax Landing Page

Premium static landing page concept for FTL Gym, inspired by the existing public website but rebuilt as a sharper international-standard parallax experience.

## Highlights

- Full English landing page
- Parallax hero, Pilates band, CTA section, and floating image motion
- 60+ clubs, 24/7 access, 6,000+ monthly classes, and 40+ class variations
- Reformer Pilates, Group Exercise, Club Network, Personal Training, FAQ
- WhatsApp, official website, self-registration, Instagram, and embedded Google Maps
- Built as static HTML with Tailwind CDN for fast Vercel deployment

## Files

- `index.html` - Complete landing page and interactions
- `.gitignore` - Local/Vercel ignores

## Public Sources

- Official FTL website: https://ftlgym.com/
- Registration: https://selfregist.ftlgym.com/
